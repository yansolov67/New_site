Violet Studio — многостраничный сайт креативной студии, посвящённый брендингу, веб-дизайну, разработке сайтов и созданию цифровых продуктов. Сайт состоит из пяти основных HTML-страниц, объединённых общей навигацией, стилями оформления и JavaScript-функциями.
Сайт Violet Studio построен на HTML, CSS и JavaScript. Его структура модульная: каждая страница отвечает за отдельный раздел, а общие стили, навигация и сценарии обеспечивают единый пользовательский опыт. Mermaid-диаграмма отражает связи между страницами, основными функциями и вспомогательными файлами проекта.
Функциональность Violet Studio обеспечивает просмотр информации о студии, знакомство с услугами, изучение портфолио и подготовку заявки. Сайт использует HTML для структуры страниц, CSS для оформления и адаптивности, а JavaScript — для интерактивных элементов и проверки формы.
